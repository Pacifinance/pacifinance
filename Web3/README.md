# Pacifinance Web3 Domain

Pacifinance owns the Web3 domain `pacifinance.x` through Unstoppable Domains.

This is kept as a brand/privacy asset and as an optional redirect to the main
website. It is not part of the core application runtime and must not be required
for login, SEO, API access, or production deployment.

Recommended usage:

- `pacifinance.com` remains the canonical public URL.
- `pacifinance.x` can redirect to `https://pacifinance.com`.
- Do not store user data, secrets, or app configuration in this folder.
- Keep the redirect static and minimal.
