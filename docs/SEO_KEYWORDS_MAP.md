## 📝 Notes

- **Keyword Cannibalization**: Avoid using same exact keyword on multiple pages
- **User Intent**: Match keywords to page intent (informational vs transactional)
- **Long-tail Focus**: Target 3-5 word phrases for lower competition
- **Local Variants**: Consider regional differences (e.g., "risparmio" vs "saving" vs "Sparen")
- **Update Frequency**: Review keyword performance quarterly and adjust strategy
